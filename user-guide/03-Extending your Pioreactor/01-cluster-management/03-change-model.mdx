## Update a Pioreactor's model from the UI

You can update the model that the software uses for each unit from the **Inventory** page.

1. Navigate to **Inventory** in the sidebar.
2. Locate the Pioreactor you want to configure and open the **Model** dropdown.
3. Pick the correct entry. The change is saved immediately.

![Inventory card with the Model dropdown and options highlighted.](/img/user-guide/03-extending-your-pioreactor/03-change-model/inventory-model-dropdown.png)

Changes to the model update any UI text, configuration safety limits, and workflows that depend on vessel geometry.

## Use a custom model

If you've built your own bioreactor on top of the Pioreactor software, you can describe it with a model YAML file. Once the file is installed, the model appears in the same **Model** dropdown.

In short, a custom model YAML must be on the leader (so it appears in the dropdown) and on every Pioreactor that will use it. See [Custom bioreactor models](/developer-guide/custom-bioreactor-models) for the file format, how to install and distribute it, and troubleshooting.
